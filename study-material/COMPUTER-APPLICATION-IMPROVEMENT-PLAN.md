# Computer Application: clearer tasks and practical support

## Review findings

The available course contains Basic chapters 1–10 and Diploma chapter 1. It already provides practical scenarios, tools, work steps, evidence lists and quality checklists. The missing bridge is between reading a task and knowing how to begin: examples, specific help, trainer preparation and a second attempt without step-by-step support.

Some activities also depend on trainer-supplied files, forms and accounts. These must be ready before class. The app stores checklist progress and evidence notes locally; it does not collect submitted files or send feedback to a trainer.

## Implemented first pass

- All 11 available chapters have task-based titles, a familiar opening problem and an explanation of why the features help.
- Course cards and opening lessons introduce the problem before the existing teaching material.
- Assignment pages provide a worked example, a help panel, guided work, an independent variation, and instructions for showing work and receiving feedback.
- Each chapter includes trainer preparation notes. The shared review method records whether each quality criterion required help or was completed independently.
- English and Hindi support is included. Existing topic identifiers and checklist keys are retained to preserve saved progress.

## Class routine

1. Ask learners to describe the problem in their own words. Check the required earlier skills.
2. Demonstrate the worked example slowly, narrating why each action is useful.
3. Let learners operate the computer during guided practice. Ask what they expected and what appeared before helping.
4. Give the changed independent task. Record help given rather than silently completing it for the learner.
5. Open the actual result and review the chapter's quality checklist. Ask the learner to explain a feature choice.
6. Give one specific strength, one correction and one next action. Allow a corrected attempt.

Suggested review record: learner | chapter | criterion | needs another attempt / completed with help / completed independently | evidence location | feedback | retry date. Store no passwords or OTPs. Checklist completion is self-report, not trainer approval.

## Next content pass

Prioritise Files and folders, Word, and Email because they form a connected assignment: organise files → create a notice → prepare its delivery.

For each chapter prepare a downloadable starter pack, an annotated finished example, and a trainer answer guide. Use fictional information. Add numbered screenshots at the exact steps where pilot learners hesitate. Include offline or no-printer alternatives where appropriate.

Then review every micro-topic, not only the chapter opening. Use: everyday problem → why the feature exists → worked action → visible result → common mistake → short practice → reflection. Retain reference tables as supporting material after the task.

Example: teach Save As by asking learners to make next month's notice while keeping this month's original. Ask them to reopen both files and show that the original did not change.

## Pilot and acceptance

Try the revised Files → Word → Email sequence with a small mixed-experience group. Record ambiguous instructions, missing materials, help requests, independently met criteria and successful retries. Use this evidence to choose screenshots and revise wording.

Before releasing each starter pack, confirm:

- A new learner can explain what to produce and start without an oral rewrite of the brief.
- Every required input exists and each step has an observable outcome.
- The final example agrees with the brief, evidence list and trainer rubric.
- A learner can complete a changed task and explain why the selected feature helps.
- Both languages, mobile reading, keyboard controls and printed instructions are usable.

Future trainer dashboards, uploads and feedback syncing need a separate design for accounts, storage and access. Do not represent the current local notes as submitted work.
