# ExamPrep question content

For every ExamPrep question added or substantively changed in this repository:

- Record a specific source reference and verify it against the supplied paper, recording, or other primary source. Label editorial corrections to source errors in the learner-facing question.
- Give objective questions a verified answer key and a useful explanation.
- Give every new written question a point-by-point `grading` rubric (or `gradingAlternatives` when the paper offers a choice). Positive criterion marks must add up to the question's marks. Include a sample answer in `explanation`; add `explanationHi` for bilingual Science and Maths questions.
- Keep free-response rubric scores provisional and set `needsTeacherReview: true`. Diagram quality, expression, and valid alternative wording require teacher review; do not present phrase matching as a final exam mark.
- Extend the ExamPrep rubric check when adding content. Existing questions in the recorded legacy allowlist are historical exceptions; do not add new exceptions without first supplying rubrics.

These rules apply to future ExamPrep content work. They do not require retrofitting the older question bank as part of an unrelated change.
