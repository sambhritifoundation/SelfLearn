    Run the real backend on your computer

    Download the starter from the tutorial, install Python 3, and open a terminal in the extracted folder.

    py server.py

    On macOS/Linux use python3 server.py. Open http://127.0.0.1:8000/?mode=server. Stop with Ctrl+C. The Python process serves this page and the API; the SQLite file stays on your computer.
