# Git, GitHub and publishing websites

Open GUIDE.html for illustrated lessons, bilingual explanations, complete AI prompts and official reference links.

Open index.html. Change the heading in your own copy, then follow GUIDE.html for Git installation, init/config, staging, commits, branching, remotes, pull requests, Pages publishing and undo. Start in this extracted folder, never an unrelated repository. Replace YOUR NAME, YOUR EMAIL and YOUR-USER placeholders before running their commands.

For a first local commit: `git init -b main`, configure your identity locally, stage index.html styles.css README.md GUIDE.html .gitignore and the visuals folder, inspect `git diff --cached`, then commit. Use an empty GitHub repository if connecting this existing local history. For GitHub Pages set main / root and verify the Actions deployment and actual public URL. A GitHub account is required to publish, but local Git practice works offline.

The included .gitignore excludes .env and common generated/private data; it does not untrack existing files or undo an exposed secret.

Official references were checked 27 September 2026. No hosting account or purchase is needed to read these lessons.
