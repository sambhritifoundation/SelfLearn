# Snake Lab: preview → open → prompt → test

1. Extract the ZIP. Keep index.html, styles.css, engine.js, game.js in the same folder.
2. Open index.html in a browser. No installation or internet is needed for the starter.
3. Try the existing controls before editing. Save a backup of the working folder.
4. Open [AI-PROMPTS.html](AI-PROMPTS.html) in your browser for expandable prompts with Copy buttons, or read [AI-PROMPTS.md](AI-PROMPTS.md) in your editor.

## Choose your route

**Improve the starter:** provide the current files, then copy one change prompt. The complete prompt includes file names, required behaviour, visual rules, example data, expected results and output format. Do not send only its title.

**Build from scratch:** use a separate empty folder and the full build prompt. The first reply contains a brief plan and complete index.html. Then ask for NEXT styles.css, then NEXT engine.js, then NEXT game.js. Save each file under its exact name. Once every file is present, open index.html and run the acceptance checks.

If an answer is cut off, ask for that whole file again. Never save half a file. If the model lacks earlier context, paste your current files again. If it cannot run the browser, perform the listed checks yourself. Use the repair prompt with exact steps, expected result and actual result when something fails.

**हिंदी:** ZIP निकालें और index.html खोलें। Backup रखें। AI-PROMPTS.html से पूरा prompt copy करें। बदलाव के लिए अपनी current files दें। नया project बनाएँ तो NEXT से एक-एक पूरी file लें। आखिरी file के बाद browser में जाँचें। Copy न हो तो box का पूरा text चुनकर copy करें।

## Daily change log

Record in changes.md: need, exact prompt, files changed, expected result, observed result, what passed/failed, and next improvement. Small reviewed changes are easier to understand and repair.

Use arrows/W A S D or touch buttons. Food adds 10 points. Pause freezes the round; Restart starts a new one. The theme, arcade-page and memory-game prompts extend the site. Best score is local to this browser.
